## 🌿 Tentang Praktikum

Repository ini berisi hasil **Praktikum 4: CSS Layout** dalam mata kuliah Pemrograman Web.

Pada praktikum ini, saya mempelajari cara menyusun elemen-elemen halaman web menggunakan HTML dan CSS agar menghasilkan tampilan website yang terstruktur, rapi, dan mudah dipahami.

## 🎯 Tujuan Praktikum

- Memahami struktur dasar dokumen HTML.
- Memahami cara menggunakan CSS untuk mengatur tampilan website.
- Mempelajari konsep Box Element.
- Memahami penggunaan properti `float` dan `clear`.
- Membuat layout website dengan header, navigasi, konten utama, sidebar, dan footer.
- Membuat halaman Home, Artikel, About, dan Kontak.

## 📘 Materi Praktikum

### 1. Box Element
Mempelajari elemen `div` dan cara memberikan gaya pada setiap kotak menggunakan CSS.

### 2. Float dan Clear
Mempelajari penggunaan `float` untuk mengatur posisi elemen dan `clear` untuk mengatasi pengaruh float pada elemen berikutnya.

### 3. Header dan Navigasi
Membuat bagian judul website dan menu navigasi agar pengguna dapat berpindah halaman.

### 4. Hero Section
Membuat bagian pengenalan website yang berisi judul, deskripsi, dan tautan.

### 5. Main Content dan Sidebar
Membagi halaman menjadi area konten utama dan sidebar menggunakan CSS.

### 6. Artikel dan Widget
Menampilkan artikel beserta gambar serta widget informasi pada sidebar.

### 7. Footer
Membuat bagian bawah website untuk menampilkan informasi penutup.

### 8. Halaman About dan Kontak
Membuat halaman informasi tentang pembuat website serta formulir kontak sederhana.
