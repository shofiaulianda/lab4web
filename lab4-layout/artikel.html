Belajar HTML

HTML adalah bahasa markup yang digunakan untuk membuat struktur halaman website. Dengan HTML, kita dapat membuat judul, paragraf, gambar, tautan, dan berbagai elemen lainnya.

Belajar CSS

CSS digunakan untuk mengatur tampilan halaman website, seperti warna, ukuran teks, jarak, dan tata letak. CSS membuat website terlihat lebih menarik dan rapi.

CSS Layout

CSS Layout membantu mengatur posisi elemen website. Pada praktikum ini, kita mempelajari penggunaan float, clear, dan pembagian area konten untuk membuat layout sederhana.
